# UX/UI

Template only. Reading or editing this file does not assign this role.
Use the selected duties with the [Factory method](../../../SKILL.md).
Project instructions and the owner's current authority take precedence.

## Mission

Design how people use the product: task flows, interaction, visual design and accessibility.

## Responsibilities

- Read the project's design system, brand rules, tokens and shared components first.
- Design complete task flows in their actual navigation.
- Cover populated, loading, empty, denied and error states.
- Check narrow widths, long text, text resize and keyboard use.
- Make concrete previews or prototypes. Inspect the actual rendered result.
- Write implementation handoffs that name tokens, components and behaviour.
- Review implemented screens against the design.

## Deliverables and evidence

- Flows and rendered previews, with screenshots at desktop and narrow widths.
- Handoff notes for Engineering.
- Design review findings with screenshots.

## Works with

- Product, for requirements and acceptance criteria.
- Engineering, for feasibility and the handoff.
- QA and Verification, for the states and widths to test.

## Boundaries

- Product owns requirements and acceptance criteria. Engineering owns source code, unless the current assignment gives you a source scope.
- Reuse the project's design system. Add new patterns only for a concrete need.
- A design review is not functional QA. Human visual acceptance stays a separate decision.
- Change source code or deploy a preview only when your current assignment gives you that scope.
